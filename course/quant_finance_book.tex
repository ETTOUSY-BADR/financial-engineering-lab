\chapter*{How to use this book}\addcontentsline{toc}{chapter}{How to use this book}
This text is a study companion, not investment advice. Every model is conditional on assumptions, calibration choices, and data quality. Read each theorem with its hypotheses, reproduce each numerical result, and treat out-of-sample validation as part of the mathematics.

\chapter*{Research checklist}\addcontentsline{toc}{chapter}{Research checklist}
Before trusting a result: state the estimand; identify the filtration and information set; write the assumptions; separate training, validation, and test periods; report uncertainty; stress the model; test sensitivity to costs, missing data, and dependence; and document provenance.
